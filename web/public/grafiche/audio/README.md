# Audio plancia

## Sigla (fallback)

Se manca `../video/sigla.mp4`, la plancia riproduce questo MP3 con logo a tutto campo.

```
web/public/grafiche/audio/sigla.mp3
```

Alternativa accettata: `web/public/grafiche/video/sigla.mp3` (stesso nome del video).

## Countdown pre-domande

File one-shot (~6 s) per lo stacco 5–4–3–2–1 (e `start_countdown` se presente):

```
web/public/grafiche/audio/countdown.mp3
```

Durante lo stacco il bed resta in pausa: parla solo questo file.
