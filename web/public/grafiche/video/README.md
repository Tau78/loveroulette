# Video plancia

| File | Uso |
|------|-----|
| `sfondo-animato.mp4` | Loop ambient sul proiettore (sempre disponibile) |
| `sigla.mp4` | **Opzionale** — intro serata. Se manca, Casa mostra «MANCA IL VIDEO» e non monta un `<video>` rotto (evita crash iOS). |

Carica la sigla da **Setup → Slide e sigla → File sigla** (resta in locale sul device / browser).
